# Visual assets

Kinshore Bay is a fictional property. The gallery, room illustrations, and site plans are generated or illustrative. The plans depict the demo layout and do not represent a surveyed site.

| Asset | Provenance |
| --- | --- |
| [Terrace and bay](../site/assets/kinshore-weekend-terrace.webp) | Generated with OpenAI ImageGen using the project’s earlier pool illustration as a reference. |
| [Club plan](../site/assets/kinshore-club-plan-expanded.webp) | Generated from the earlier concept plan. Map pins and labels are rendered by the application. |
| [Garden Studio](../site/assets/garden-studio-warm.webp), [Poolside](../site/assets/kinshore-apartment.webp), [Family Two Bedroom](../site/assets/family-twin-bedroom.webp) | Generated room concepts. The diagrams in the application explain the fictional sleeping layout. |
| [Grill pergolas](../site/assets/kinshore-grill-pergolas.webp) | Generated for the Saturday programme. |
| [KB mark](../site/assets/kinshore-kb.webp) | WebP derivative of the mark supplied for the project. |
| [Site screenshot](media/kinshore-bay-home.jpg) and [walkthrough](media/kinshore-bay-demo.webm) | Captured from the Kinshore Bay demo. |
