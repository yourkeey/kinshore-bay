# Kinshore Bay — визуальный прототип

После установки Django из [crm/requirements.txt](../crm/requirements.txt) запустить из корня:

```powershell
python site/preview.py
```

Открыть `http://127.0.0.1:8765/site/index.html`. Остановка — `Ctrl+C`. Команда запускает миграции, добавляет исходный инвентарь при его отсутствии и поднимает Django на loopback. Если порт занят, используйте `python site/preview.py --port 8766` и откройте тот же путь на порту 8766.

Django отдаёт содержимое общего каталога с актуальными демо-тарифами и вместимостью из CRM. Подбор проверяет свободные апартаменты на выбранные даты. Гость отправляет заявку и получает номер в My stay. История доступна в текущем браузерном сеансе при включённых cookies.

Картинки комплекса и интерьера — сгенерированные концептуальные изображения, а не фотографии или точный генплан. У каждой категории есть своя иллюстрация интерьера. Шрифты загружаются из Google Fonts при наличии интернета; есть системные запасные варианты.

## Гостевой маршрут 2.0

Главная открывается сценой уикенда на террасе. «Floor plan & kitchen» открывает схему и оснащение, «Check dates» переводит в подбор для выбранной категории. На плане 24 точки, включая гриль-беседки возле Bay Kitchen. На узком экране «Overview» оставляет ключевые метки на плане и полный список в легенде. «Show walk route» подсвечивает Garden path от ресепшена через Pine terrace до выхода к пляжу. Субботняя программа ведёт к местам на карте.

В подборе клавиши со стрелками перемещают фокус в календаре, а Escape возвращает его к кнопке дат. Тарифы и вместимость берутся из CRM. Даты, гости, бюджет и категория сохраняются в пределах вкладки при доступном sessionStorage. Явная ссылка на категорию имеет приоритет. Если фильтры скрыли доступные варианты, выдача предлагает снять их. При ошибке сети можно повторить запрос с теми же датами.

Для браузерной регрессии запустите `python site/check_guest_route.py` из корня в окружении, где установлены `requirements-dev.txt` и Chromium для Playwright. Проверка стартует Django на свободном локальном порту с временной SQLite. Для установленного Chromium-браузера задайте путь в `KINSHORE_BROWSER`. [Установка и тесты](../README.md#run-the-tests)

## Прогулка в My stay

Выберите поездку с пятницы по воскресенье и отправьте заявку. Подтвердите её на ресепшене в другом профиле браузера, затем обновите **My stay**. В карточке появятся путь от въезда до корпуса, список включённых услуг, субботняя прогулка и два занятия без записи. Число свободных мест на прогулку берётся из CRM. После записи её можно отменить здесь же. Список по сеансам находится в разделе **Walks** ресепшена.

Перед отправкой в **Review request** укажите сколько гостей младше 18 лет, будет ли питомец и приедете ли на машине. Reception видит ответы вместе с заявкой. Крытые места занимают по приезде. При заполнении используйте открытую стоянку. Беседку оформляет сотрудник в **Grill pergolas**. После обновления My stay показывает назначенный стол и время.
